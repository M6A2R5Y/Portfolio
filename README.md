# Mary Kinyanjui - Personal Portfolio

A sleek, responsive, and glassmorphic personal portfolio website designed to showcase professional experience in remote customer operations and technical skills in software engineering.

## 🚀 Live Demo
Open the [index.html](index.html) file in any web browser to view the interface.

## ✨ Features
- **Modern Design**: Responsive CSS Grid and Flexbox layout featuring glassmorphism and smooth transition animations.
- **Theme Switcher**: Instant transition between Light and Dark modes, persistent using browser `localStorage`.
- **Dynamic Projects Filter**: Clean, tabbed interactive filters for showcasing TypeScript/JS, Python/ML, C, and Java repositories.
- **Visual Skill Meters**: Graphic progress bars showing proficiency across support channels, systems (Zendesk, Shopify, Gorgias), and development tools/languages.
- **Timeline Milestones**: Professionally structured resume milestones tracing remote operations roles.

## 🛠️ Tech Stack & Assets
- **Layout/Structure**: Semantic HTML5
- **Styling**: Modern Vanilla CSS (variables, transitions, viewport animation keyframes)
- **Logic**: Vanilla JavaScript (theme detection, DOM filtering, Scroll Animations Observer)
- **Icons**: Clean, inline SVG icons for responsive scaling and fast load times
- **Fonts**: Outfit & Inter (via Google Fonts)
